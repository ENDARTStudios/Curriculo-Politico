# Monetização e Preços

## Princípio
O Currículo Político é **100% gratuito para o cidadão**. Sem paywall, sem
anúncios, sem venda de dados. A monetização, quando existir, não pode
comprometer a neutralidade algorítmica.

## Modelo Atual (v0 — Custo Zero)
| Serviço | Tier | Custo |
|---|---|---|
| Vercel | Hobby | $0 |
| Supabase | Free (500MB) | $0 |
| Cloudflare | Free | $0 |
| Sentry | Developer (5k eventos) | $0 |

## Modelo Futuro (v1 — quando houver escala)

### Receitas possíveis
1. **GitHub Sponsors** — doações voluntárias (já implementado em /apoie)
2. **Pix** — doações pontuais (já implementado em /apoie)
3. **API comercial** — acesso rate-limited expandido para imprensa/pesquisadores (futuro)
4. **Relatórios customizados** — análises sob demanda para ONGs (futuro)

### O que NUNCA faremos
- Anúncios (comprometeria a percepção de neutralidade)
- Venda de dados de usuários (LGPD + princípio ético)
- Paywall para o cidadão (missão = acesso universal)
- Sponsorship de partidos ou candidatos (conflito de interesse)
