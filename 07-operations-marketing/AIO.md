# AIO — AI Integration & Operations

## Uso Atual de IA
| Feature | Tecnologia | Status |
|---|---|---|
| Resumos de projetos | Templates por categoria | ✅ Ativo |
| Classificação de tags | Keyword matching | ✅ Ativo |
| Identidade (matching) | Algoritmo próprio | ✅ Ativo |

## Uso Planejado
| Feature | Tecnologia | Status |
|---|---|---|
| Resumos reais de leis | Ollama local (llama3.2) | Planejado |
| Classificação semântica | Typesafe AI ou embeddings | Planejado |
| Análise de impacto | LLM com Pydantic schema | Planejado |
| Filtro de afinidade | Embeddings + voting history | Planejado |

## Princípio de IA
Nenhuma IA altera o IDIP. IA é usada apenas para tornar dados públicos mais
acessíveis (resumos, classificação) — a nota factual vem de dados oficiais.
