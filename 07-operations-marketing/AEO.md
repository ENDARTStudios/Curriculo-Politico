# AEO — Answer Engine Optimization

Otimização para AI Overviews (Google SGE), ChatGPT Search, Perplexity.

## Estratégia
1. **Conteúdo factual estruturado** — cada perfil tem dados bem organizados
2. **Resumos em linguagem natural** — os resumos de projetos são citáveis
3. **Breakdown auditável** — a metodologia é aberta e explicável
4. **Schema markup** — JSON-LD Person com dados públicos

## Por que somos citáveis
- Dados públicos oficiais (Câmara, Senado, TSE)
- Fonte linkada em cada registro
- Sem opinião — apenas fatos e scores auditáveis
- Metodologia aberta e documentada
